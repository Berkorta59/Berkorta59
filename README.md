## 🚀 Featured Projects

### 🎙️ [SoundtoText](https://github.com/Berkorta59/SoundtoText)
**Local AI-powered audio and video transcription**

A desktop application that converts speech into text using Faster-Whisper. Designed for local processing, offline use after model downloads, and multiple transcript export formats.

`Python` `Faster-Whisper` `Qt` `AI`

### 🎵 [cli-music-player](https://github.com/Berkorta59/cli-music-player)
**A music player for the terminal**

A Rust-based TUI music player featuring fuzzy search, playlists, album art, an FFT visualizer, and customizable themes.

`Rust` `TUI` `Audio`

### ⏱️ [Pomofocus](https://github.com/Berkorta59/Pomofocus)
**A modern Pomodoro productivity app**

A PyQt6 desktop timer with system tray integration, sound notifications, customizable durations, productivity charts, and streak tracking.

`Python` `PyQt6` `Productivity`

### 📥 [yt_dlp_gui](https://github.com/Berkorta59/yt_dlp_gui)
**A multilingual media downloader GUI**

A PySide6 interface for yt-dlp with download queues, format selection, metadata previews, download history, and dark mode.

`Python` `PySide6` `yt-dlp`

### 🎬 [Gather-P2P-Watch-Party](https://github.com/Berkorta59/Gather-P2P-Watch-Party)
**Watch together, without accounts**

A peer-to-peer watch party application supporting rooms, screen sharing, system audio, microphone input, and chat.

`TypeScript` `WebRTC` `Peer-to-Peer`

### 🖥️ [CanvaDesktop](https://github.com/Berkorta59/CanvaDesktop)
**A desktop wrapper for Canva on Linux**

An Electron-based project that brings Canva into a desktop application workflow.

`JavaScript` `Electron` `Linux`

### 🎸 [Rockwy](https://github.com/Berkorta59/Rockwy)
